# RxJS Epics Tutorial - Interactive Games Learning Guide

Welcome to learning RxJS Epics through building interactive games! This tutorial will take you from understanding the basics to building real-time game mechanics.

## 📚 Learning Path

| Level | Project | Concepts Covered |
|-------|---------|-------------------|
| 1 | [Clicker Game](projects/01-clicker-game/) | Basic Actions, Epic creation, Stream merging |
| 2 | [Reaction Timer](projects/02-reaction-timer/) | Timers, debounce, delay operators |
| 3 | [Snake Game](projects/03-snake-game/) | Keyboard input, game loop, state management |
| 4 | [Space Invaders](projects/04-space-invaders/) | Collision detection, multiple epic coordination |

## 🎯 Quick Start

```bash
cd rxjs-epics-games
npm install
```

Then explore each project in order!

## 🔑 Key Concepts You'll Learn

1. **What are Epics?** - Long-running observables that listen to actions
2. **Action Streams** - The "input" to your epics
3. **Side Effects** - Handling external concerns (storage, network, etc.)
3. **State Management** - Using epics to transform actions into state changes
